# ⚡ Quick Start Guide - Maritime Transformation

## Step 1: Verify Files (30 seconds)

Check that these files exist:
```
✅ index-maritime.html
✅ about-maritime.html
✅ contact-maritime.html
✅ fleet-management.html
✅ shipboard-software.html
✅ marine-ai.html
✅ maritime-training.html
✅ maritime-analytics.html
✅ CSS/pages/maritime.css
```

---

## Step 2: Backup Originals (1 minute)

```bash
# Create backup folder
mkdir backup-original

# Backup your current files
cp index.html backup-original/
cp about.html backup-original/
cp contact.html backup-original/
```

---

## Step 3: Deploy Maritime Version (1 minute)

```bash
# Replace with maritime versions
cp index-maritime.html index.html
cp about-maritime.html about.html
cp contact-maritime.html contact.html
```

---

## Step 4: Test (2 minutes)

Open `index.html` in your browser and check:
- ✅ Page loads with maritime theme
- ✅ Navigation works
- ✅ All buttons clickable
- ✅ Forms work
- ✅ Mobile responsive

---

## Step 5: Go Live (1 minute)

Upload to your server:
```bash
# Upload all files to your web server
# Or commit to Git and push
git add .
git commit -m "Maritime transformation complete"
git push origin main
```

## 🆘 Need Help?

### Common Issues

**Q: Maritime CSS not loading?**  
A: Clear browser cache (Ctrl+Shift+R)

**Q: Navigation not working?**  
A: Check that SCRIPT/common.js is loaded

**Q: Forms not submitting?**  
A: Verify Formspree endpoint in contact form

**Q: Mobile menu not opening?**  
A: Check hamburger menu JavaScript
